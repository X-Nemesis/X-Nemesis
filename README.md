### // what this is

Advanced AI prompts for developers. Tested. Specific. No filler.

### // what you'll find

- `debugging/` : find root causes, not symptoms
- `code-review/` : catch what humans miss
- `architecture/` : design before you build
- `refactoring/` : clean code without breaking it
- `testing/` : edge cases you forgot to think of
- `security/` : audit like an attacker, fix like a defender

### // rules

- Every prompt is tested on real models
- Every prompt has an example input and output
- No recycled lists

<details>
<summary><b>Root-cause debugger</b> (click to open)</summary>

<br>

```text
You are a senior engineer debugging a production issue.

Context:
- Language/stack: [stack]
- Expected behavior: [what should happen]
- Actual behavior: [what happens]
- Error/logs: [paste here]
- Code: [paste here]

Do this in order:
1. List 3 hypotheses ranked by likelihood, with the evidence for each.
2. Name the single check that would confirm or eliminate the top hypothesis.
3. Only after that, give the minimal fix. Do not rewrite unrelated code.
4. State what could still be wrong after your fix.
```
